# assets

负责私有上传、解码校验、访问授权与血缘。公开入口为 `manifest.py` 和 `api.py`，复杂用例在 `service.py`。

数据归属：Asset/AssetInput；不决定权益价格。依赖见 manifest；模块通过业务服务调用协作，不能直接越过授权和事务边界。数据库变更统一由 Alembic 执行；关闭模块保留其历史表。

V1.3：上传支持 reference/base/style，用途仍在服务端校验。reference 绑定已声明授权的人物；base/style 无人物槽，但要求声明图片使用权。项目素材保存限额取自目录，模型单次输入限额取自网关。作品可作为底图继续编辑；私有读取遍历完整祖先血缘，清理在删除每代前标记后代，不因连续编辑而绕开授权撤销。
