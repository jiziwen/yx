# operations

负责受控管理员查询及审计。公开入口为 manifest.py/api.py；jobs.py 提供调用详情、带 revision 的核对与取消。核对仅查询已保存的原任务，写审计，不提供重新生成、手填成功/费用或强制退款。

`entitlements.py`提供管理员搜索客户、选择所属项目、补发次数和查询发放流水；复用commerce的Account/EntitlementEvent，余额、流水、Audit同事务提交，UUID请求键和数据库锁防重。不提供撤回、支付或生成操作。前端入口`/entitlements`，说明见[后台次数发放](../../../../../docs/后台次数发放.md)。

数据归属：Audit；不绕过拥有者/授权展示用户图片。依赖见 manifest；模块通过业务服务调用协作，不能直接越过授权和事务边界。数据库变更统一由 Alembic 执行；关闭模块保留其历史表。

模型调用观测：`/api/v1/admin/model-calls`按图片任务合并后固定20条分页，`/{call_id}`展示原始提示词、提交入参和最近出参，`/{call_id}/payload`读取单次操作；两个详情接口都写审计。前端使用弹框，逐次明细单独分页。网关统一记录、适配器在发送前保存实际HTTP参数及模型；图片二进制只存摘要，流式回复合并保留已收内容。记录与业务事务分离，生成仍经原确认链路；数据说明见`docs/后台模型调用.md`。
