# knowledge

负责知识原文私有存储、不可变版本、持久索引任务、中文分词、1536维embedding、发布/下架、公开指南和受控引用。未发布/未就绪/未批准/过期/撤销的版本不参加检索；价格和业务状态仍从业务服务读。

models/schemas定义状态与契约；service处理导入/发布、混合检索和引用资格；worker在事务外执行embedding；tools按角色注册只读查询；api/manifest负责权限和可停用装配。原文解析不执行脚本或抓链接。知识任务不占照片权益，也不允许Agent发布文档。

配置、接口、真实模型与验收见[完整M2说明](../../../../../docs/M2完整交付与验收.md)。
