# conversations

创作与客服消息的权威存储、分页、失效通知和人工交接。创作会话唯一项目约束保留；support_only使用独立拥有者/范围，可绑定项目或无项目。客服请求人工会撤销自动提交权，员工领取后才可回复；交还仅影响下一条新消息，不重放历史。

api/events/history为原项目协议；support/support_api/support_schemas/support_events为独立客服。所有读取重新校验拥有者、项目和隐私；员工只能处理待领取或本人接管的客服，不取得人物/照片/草稿。隐私清理也覆盖没有AgentRun的人工消息。

配置、锁序、迁移与验收见[完整M2说明](../../../../../docs/M2完整交付与验收.md)。
