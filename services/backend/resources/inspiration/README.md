# 内测套系素材

八张 WebP 复制自工作区 `apps/web/public/images/`，原始来源为 `参考ui/public/images/`，来源说明见用户端 `ASSETS.md` 与 `原素材说明.md`。本轮未生成新的摄影图片。

当前镜头在 `catalog.yaml` 全部标为 `development_only: true`，仅供内测 UI 和本地测试卡片流程。生产目录会过滤这些镜头；真实图片插件也拒绝使用内测镜头。对外开放前，运营应替换为具有明确展示、衍生和模型处理授权的套系素材，记录来源与授权，再配置为正式镜头。不能仅通过复制文件或删除标志声称授权已经完成。

现可通过后台`/theme-materials`上传新图片，或为既有镜头填写真实来源和用途后“保存并生效”。操作者和摘要自动记录，实时发布目录保存在数据库，无需修改本文件或重启。安装新功能不会自动批准这些既有样片，初始YAML状态保持。详见[后台主题素材管理](../../../../docs/后台主题素材管理.md)。

样片由后端配置目录注册、解码去 EXIF 并计算内容摘要。浏览器使用公开的样片 API，不能传服务器路径；用户上传图片在独立私有存储，不进入此目录。
