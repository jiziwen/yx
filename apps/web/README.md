# 映序用户端

React/TypeScript/Vite 用户应用，入口 `src/main.tsx`。正式首页与工作室采用已确认的梦幻摄影师体验；项目、人物、方案、任务和作品来自真实 API。开发地址端口 5273，`/api` 代理 8100；生产使用 Nginx 代理。

`themes/*/manifest.ts` 自动发现主题，`modules/*/manifest.tsx` 自动发现功能。主题切换不会重建业务路由；业务数据由 TanStack Query 读取，本地表单使用 React Hook Form/Zod。

`src/features/atelier` 承载共享视觉、真实工作室查询、项目创作 Agent和交付视图；`src/config/experience.ts` 配置默认主题、摄影师及引导开关。manifest 可选 `atelier` 配置标题、图片焦点及色谱，可替换 Hero。模型路由、能力与密钥始终在后端配置。

首页想法仅保存在应用内存，登录后经新建项目绑定到工作室草稿；不会进入 URL 或浏览器历史。对话通过后台 LLM 与持久化会话/Run 理解和追问；明确提出的可撤销修改同步草稿，额外建议须点击采用；图片仍需一次明确确认后才生成。长期要求另需明确确认保存，工具仅限只读。

正式创作：人物授权/上传 → 编辑并保存新提案 → 冻结版本确认 → 权益预占与 Job → 私有作品。修改草稿后关闭旧卡确认，其他页面的新版本不会覆盖本地未保存内容。桌面分栏、手机对话/画布切换；结果区不使用原型样片。`/preview` 仍可对照原型，详见 [正式体验改版](../../docs/正式体验改版.md)。

根目录运行 `pnpm dev:web`，需另启动 API 和 Worker；一键运行见根 README。`pnpm --filter @yingxu/web typecheck` 与 `build` 已验证，产物 `dist`。密钥不能放 VITE_* 或公共资源。

V1.3：正式 `/inspiration` 支持配置化套系和镜头选用，工作室接入拍同款、设计写真、单底图编辑与零图片文生图。素材用途、模型限制、提案与确认均由真实 API 支持；生成仍取决于部署插件，本地默认交付开发测试卡。详见 `docs/四种创作方式接入.md`。

V1.8：SSE 通知与权威快照共同恢复会话，提案显示发送时原草稿与建议对比；无 token 逐字输出。详见 [实时对话与提案对比](../../docs/M2实时对话与提案对比.md)。

V1.9：真实 LLM 的 reply 按原生片段逐步出现；replyStream 按 Run/attempt/seq 替换前缀，旧连接/尝试不能接到新回复。只有最终提案可应用，断线后恢复单条最终消息；详见 [逐字流式回复](../../docs/M2逐字流式回复.md)。

V1.10：新增配置化创作需求卡（用户明确确认才保存）、消息 cursor 分页与阅读位置保留、带原话来源的只读历史查询。替换/删除要求后旧记录不再供 Agent 检索；图片仍须用户确认。配置与验收见 [创作需求卡与历史管理](../../docs/M2创作需求卡与历史管理.md)。
