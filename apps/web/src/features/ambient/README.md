# Flower Valley 背景

背景直接运行参考效果的原版 Gladeye 场景，替换此前自写的 WebGL 模拟实现。
地形、花朵分布、相机路径、花叶图集、鼠标响应、灯光、景深、Bloom 和颗粒后处理
均来自原版。没有再用自行生成的花床或漂浮花朵替代原场景。

`FlowerValleyBackground.tsx` 挂载在应用壳首个子节点，使用固定地址
`/flower-valley/index.html` 的本地 iframe。iframe 隔离原引擎的全局变量、DOM 和样式，
不会接管业务页面。原脚本与素材全部从本项目加载，不依赖原站在线可用。
资源来源和编译包的唯一补丁见 [原版资源说明](../../../public/flower-valley/README.md)。

## 输入与生命周期

- 背景 `pointer-events: none`，不获得焦点；父页面通过校验来源的消息转发鼠标位置和滚轮。
  父页面监听器保持 passive，不阻止页面滚动、表单、选择文字或导航。
- 使用原版的鼠标响应，不将任意业务按钮的 hover 绑定为原站 CTA 的全局花朵散开效果。
- 页面进入后台时暂停原引擎和虚拟滚动器的动画帧；恢复时消耗旧时钟间隔，避免镜头跳动。
- 减少动态偏好跳过开场转镜并保留原场景静帧；尺寸变化后重新绘制静帧。
- WebGL 或素材失败时显示同一原版场景的静态回退图；上下文恢复后恢复场景。
- 真实卸载移除 iframe 并销毁原场景；React StrictMode 的 effect 清理只移除父页面监听器。
- 不初始化原版音频管理器，也不请求音频文件或权限。

## 主题

六种主题保留近黑夜景。`themes/nightAppearance.ts` 从原主题 token 派生深色界面和浅色文字。
场景只通过小幅 CSS 色相调整适应主题；默认海岛叙事保持原版色相。
主题切换不改变 iframe 地址、不重建花谷，也不重置表单或创作草稿。
`palette.ts` 为加载与失败时的静态回退层提供背景色，不修改原版着色器。
首页完整展示场景，其他业务路由通过 `subtle` 遮罩减淡。

## 验证

构建：`pnpm --filter @yingxu/web build`

浏览器验收：`pnpm exec playwright test tests/e2e/flower-valley.spec.ts`

验收检查真实原版资源、WebGL、动态与静态偏好、六主题保留同一 iframe 和输入、窄屏布局、
加载失败回退和上下文恢复。画面以原版为标准，不再用自定的花朵覆盖率或噪点指标改变场景。
