# 映序管理端

独立 React/TypeScript/Vite 应用，入口 `src/main.tsx`。端口 5274，代理 API 8100。当前提供概览、脱敏用户列表、生成任务、模块/网关/功能配置与审计；没有用户照片访问或未知任务重发操作。

M1 新增“生成任务→查看详情”：读取稳定请求键、接单凭据状态、错误、数值用量、估算/确认费用和耗时；未知费用显示未知。“查询原任务”只查询已保存凭据，带当前 revision 并写审计；排队取消返还一次，提交后仅记录取消请求。管理界面不能手填成功、费用或重新发起生成。

“302.AI 模型”页 /models 可读取账号实际模型列表，分别设置图片操作模型/质量/输入上限与语言模型/输出预算，并以 expected_revision 发布不可变版本。API 与 Worker 自动读取新版本，旧任务保留原配置；密钥仍只在后端 .env。当前 gpt-image-2 / low 与 claude-sonnet-5-5 已发布并真实联调，工作室 Agent 对话另行接入。

管理登录与用户登录使用独立签名及 HttpOnly Cookie，所有运营 API 需要服务端管理员角色。开发模式仅首次初始化默认账户；数据库模式从受控 CLI 开通账户，密码摘要持久化，普通用户会话不能复用。鉴权和目录查询使用 OpenAPI 生成的类型化客户端。配置见根 README 和后端 `.env.example`。

根目录运行 `pnpm dev:admin`。`pnpm --filter @yingxu/admin typecheck`、`build` 已验证；静态产物 `dist` 独立发布。

V1.11：M2全量功能已补齐：知识导入/索引/发布/指南、混合RAG与授权引用、独立客服与人工接管、员工权限、公开Run Step及精确Release/固定评测。图片仍须用户确认；主题/网关/工具可配置、可插拔。统一工程检查 `pnpm check:m2`，真实重复抽样与人工质量批准单独记录。入口和当前验收见[完整M2说明](../../docs/M2完整交付与验收.md)。
