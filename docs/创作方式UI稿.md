# 创作方式 UI 稿

日期：2026-10-22。状态：用户已确认本稿；后续正式接入见[四种创作方式接入](四种创作方式接入.md)。本文件保留原型阶段的交互说明，不作为正式接口契约。

预览入口：[首页](http://127.0.0.1:5273/preview)、[灵感库](http://127.0.0.1:5273/preview/library)、[工作室](http://127.0.0.1:5273/preview/studio)。正式页面保持现有行为。

## 体验组织

沿用奶油、雾紫、柔光、圆角与 Lumi 陪伴式工作室。首页提供四种开始方式，进入同一工作室后按方式呈现素材区，不要求用户了解底层模型接口。

| 入口 | 图片输入 | 主要界面 |
| --- | --- | --- |
| 拍同款 | 每任务一张样片底图 + 本次勾选的人物参考 | 套系镜头多选、人物参考、提案人物对应 |
| 设计写真 | 人物参考，可附套系氛围参考 | 风格灵感、人物素材、创作描述 |
| 修改照片 | 一张底图 | 保留项、修改要求，无额外人物照要求 |
| 从文字开始 | 零张图片 | 画面描述，说明人物不对应用户本人 |

## 灵感库

写真套系与网站界面主题分开。每个套系可选多个镜头，支持「拍选中的同款」与「只借鉴这份氛围」。前者分别使用底图，后者将选中图片视为风格参考。首稿使用同一既有样片的三种裁切演示套系结构，页面明确注明，正式上线应替换为独立且有授权的样片。

## 素材和限制

底图、人物参考和风格参考分别标示。人物参考可以多张保留、按次勾选，并绑定人物 A/B；同款提案明确指定对应底图中的主角，双人位置重复时阻止确认。

拍整组时按镜头拆开，每个任务只传该底图与共用的人物参考。显示每任务的输入计数。两套可切换的本地演示规格展示总图片上限、人物参考上限及人物数；超限时保留用户选择、提示调整、禁用确认，不静默截断输入。真实模型的能力应由后端网关提供，本稿不代表已验证的模型能力。

上传仅本地 Object URL 预览，接受 10 MB 内的 JPG/PNG/WebP；可用示例素材体验。用户文本、图片及提案不放入 URL、历史 state、localStorage 或服务端。切换创作方式保留本页素材；切到不需要人物参考的方式时明确不使用这些照片。退出或刷新丢失本页内容。

## 提案与后续

准备画面 → 创作提案 → 确认清单 → 占位作品预览。提案展示方式、输入用途、人物对应、修改方向、画幅、每镜头版本数与总张数。费用明确等待正式接入计算，原型不显示虚构价格或余额。确认后只展示明确标注的既有样片占位，可点击「以此为底图继续修改」。无网络上传、Job 创建、权益消耗或模型调用。

Lumi 对话采用本地固定回复，用户消息点击「加入提案」后才写入便签，不代表真实 Agent 已接入。

## 本轮核验

前端类型检查与构建；浏览器检查桌面和手机布局、套系多选入场、实际本地选图预览、超限禁用确认、零图片可确认、单底图编辑、人物对应、确认清单与继续修改。截图存放于忽略目录 `.data/creation-preview/`。完整 M0 验收与真实供应商评测不属于本次原型核验。
