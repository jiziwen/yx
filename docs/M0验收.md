```sh
pnpm install --frozen-lockfile
```

此命令需要 Docker，先检查代码质量和类型，再检查契约漂移、后端、客户端、样例定义、临时 PostgreSQL、临时 Redis、独立浏览器流程和两个构建产物。任何一项失败即返回非零；不会通过跳过 PostgreSQL/Redis/浏览器来报告全通过。

浏览器测试使用 5373 / 5374 / 8200，现有本地工作室使用 5273 / 5274 / 8100；每轮浏览器测试数据库独立创建。测试退出会回收本轮服务；不会停止用户原有工作室或其他项目。数据库/Redis 验收使用临时容器，结束只删除本次创建的容器。

## 管理开通与迁移

新增迁移 `e3abaca68af6` 只创建 `admin_credentials`，不会改写原项目和用户。回退该迁移会删除管理密码摘要，因此只能在已备份的维护环境操作；原业务数据保留。PostgreSQL 验收覆盖回退/再升级、业务记录保留和 Alembic 模式漂移。

数据库模式不会把 `ADMIN_PASSWORD` 当成有效登录凭证；先执行受控 `create-admin`，再使用保存的密码摘要。默认开发账户的自动初始化只在 development 模式执行一次，环境变量变更不能覆盖已开通密码。密码可通过交互或 stdin 进入 CLI，不放到 argv、日志、客户端或公开响应。
