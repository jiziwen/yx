
## 图片提示词编译插件

`creation_prompt: {entrypoint: app.modules.executions.prompts:compose, version: creation-v5-zh, options: {}}`。可信函数签名为`compose(spec, inputs, options) -> str`，逐交付项返回非空、至多16000字符的实际提示词；插件应按输入角色区分底图/人物/风格，不负责模型路由、授权或执行。默认编译器只发送中文画面要求和必要的图片序号、人物位置说明，不拼入套系显示名称、空内部字段、人物ID或上传路由说明；用户明确要求的外文文字保持原样。保存方案时冻结文本与策略摘要并纳入方案哈希；Worker使用冻结文本。公共目录返回当前提示词策略摘要，工作室不复用旧规则的未确认卡，服务端确认也会核对摘要；已确认任务保持冻结文本。模型切换仍在网关，主题素材仍由实时目录发布，两者不与提示词入口绑定。配置变更属于部署级，不能由浏览器传入import路径。

## 成图下载与代理DNS

`integrations/result_download.py` 处理已登记成图主机的公网地址核对。代理或混合DNS结果通过固定HTTPS解析器核对A记录，下载固定连接验证后的公网IP；HTTP Host和TLS服务名仍为原登记域名，证书校验、域名白名单、禁止重定向、30MB上限及不转发供应商令牌的约束保持生效。HTTPX/httpcore使用项目锁定版本，代理CONNECT的TLS服务名通过局部网络后端包装保留，覆盖直连与代理契约测试。核对与文件下载只读取已提交任务，不重新发送生图请求。查询恢复为pending时清除旧核对错误，交付仍按原Job幂等结算。
