# 后台主题素材管理与即时发布

更新时间：2026-10-23。

## 入口与操作

本地管理后台：`http://127.0.0.1:5274/theme-materials`，侧栏“主题素材”。仅admin可访问；客户与staff不能上传、发布或查看未公开素材。

1. 选择已有套系，或点击“新增套系”，填写名称、稳定标识、项目类型、氛围、说明及外观主题标识。套系业务配置独立于前端外观主题插件；新建套系不要求新增前端代码。已有套系的标识与项目类型保持固定。
2. 为新镜头选择JPG、PNG或WebP，点击对应“上传镜头图片”。后端按配置限制字节数，解码验证64像素以上、最多3000万像素，去除EXIF并标准化PNG，计算内容摘要。上传成功只获得管理员预览，不会自动公开、出图或消耗次数。
3. 每张图填写真实来源及使用依据，分别勾选“网站展示”“衍生创作”“发送给模型处理”，并设置镜头可用状态、名称和单/双人位置。替换图片后旧来源与用途会清空，需要重新填写。已有内测图也可直接补充来源与用途，无需重新上传或手算摘要。
4. 点击“保存并生效”。当前管理员自动记为本次确认人，来源、用途与服务端图片摘要绑定，保存就是一次发布，不再要求另点审核/批准。只允许展示的图可在灵感库浏览；用于真实图片创作需三项用途都允许。主动视觉分析只要求展示及模型处理用途，不要求衍生创作。
5. 工作室在窗口聚焦及每5秒读取最新目录；API、Agent与Worker使用同一个数据库发布指针，不需要为每次保存改YAML或重启。保存目录不会修改私有草稿、添加人物授权、领取次数或自动生成图片。

当前「测试」项目要使用的既有样片，位于“雾光艺廊 → 镜头1『故事的开场』”。管理员填写来源和三项允许用途后保存，工作室即可按最新能力准备确认卡。仍由用户最后确认生成。

取消“镜头可用”、取消展示、移除镜头或停用套系，保存后即从相应用户目录下架；原图及历史发布记录保留，管理员可核对。未填写来源时不能开启任何用途；不会因为安装管理入口就默认批准现有内测样片。

## 版本、存储与执行边界

- 新增`CatalogMaterial`、`CatalogRelease`、`CatalogHead`，由`f36c10421b22`迁移创建。迁移只新增表和空指针，不改旧项目、权益、配置文件、样片状态或模型配置。有实际上传/发布记录时拒绝直接有损回退。
- YAML继续作为初始目录及环境级能力配置；第一次后台保存后，数据库完整发布快照为运行目录。之后通过后台维护快照。原YAML文件不被改写，业务不依赖HTTP请求修改部署文件。
- 图片使用现有可插拔Storage网关保存不可变对象键，当前为本地存储；数据库只记录摘要和引用，不保存照片正文。后续迁移存储时需要迁移这些目录对象，和已有用户素材使用相同存储边界。
- 发布事务锁定固定目录指针，校验`expected_revision`，新增完整快照并写操作审计，再切换指针。并发不同编辑只有一份可成功，旧版本不会覆盖新版本。用户收到冲突时本地编辑保持，核对后可“重新载入生效版本”。
- UUID请求键防止同一上传/保存动作重复执行；同键内容不同拒绝。保存中的字段冻结，断网/5xx保留原请求，并按管理员ID分区放在sessionStorage，刷新后复用原键重试。成功后清除；不在浏览器保存密码、Cookie或图片正文。新一笔有意发布使用新键。
- “发布记录 → 查看本版”可只读查看那版图片、来源、用途、确认人与摘要；历史预览读取该版不可变对象，不会把旧版本重新发布。公开内容只允许访问当前可展示镜头，不会通过历史URL绕过下架。
- 公共目录不返回存储路径、来源原文或内部审核字段，只返回展示元数据和创作可用标志；未公开及历史图片通过管理员API预览。图片URL携带摘要，换图后浏览器会获取新图片；内容与摘要不符时拒绝使用。
- 冻结输入同时绑定图片摘要、用途和人物位置。保存新图、撤回用途或下架后，旧确认卡/排队任务会被阻止，不会静默替换成新图执行；预占按既有失败结算规则释放。已发往供应商的在途请求仍按原冻结请求查询和结算，不重新提交。
- Agent的代码/模型/提示词质量Release与管理员发布的运行目录数据版本分开记录；代码质量门禁保留，单次目录保存不要求重新审批代码。每轮另冻结运行目录摘要，目录更新后旧轮次的迟到回复不能写入右侧配置，用户可基于新目录重新发送。
- 主题素材、模型网关、权益和人物授权独立。补齐素材用途不会绕过模型输入上限、模型发布规则、人物授权或用户最终出图确认。

当前目录最多100个套系、每套系12个镜头；单张上传字节上限沿用`MAX_UPLOAD_BYTES`。管理页面可以新增/修改套系、上传替换图片、配置来源与用途、排序/移除/下架镜头、保存生效及查看版本。没有增加支付、自动退款或自动批量批准素材功能。

## API

以下路径以`/api/v1`为前缀，所有管理接口均要求admin身份。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/admin/theme-materials` | 读取管理目录及全局revision，含已停用条目 |
| POST | `/admin/theme-materials/images` | multipart上传file、request_key，返回管理员预览ID |
| GET | `/admin/theme-materials/images/{id}/content` | 仅管理员预览上传图片 |
| POST | `/admin/theme-materials` | request_key、expected_revision、完整style字段；保存并发布 |
| GET | `/admin/theme-materials/releases` | 按版本分页查询发布人、时间和记录ID |
| GET | `/admin/theme-materials/releases/{id}` | 只读查看历史版本来源和用途 |
| GET | `/admin/theme-materials/styles/{style}/shots/{shot}/content` | 管理员预览当前/指定历史版本的镜头 |
| GET | `/web/catalog` | 实时公开目录，不依赖重启 |
| GET | `/web/inspiration/{style}/{shot}/content?checksum=...` | 当前可展示镜头内容；摘要不匹配拒绝 |

## 验证与本地部署

测试图片、来源和用途全部为明确标识的合成夹具；没有代用户批准真实素材，也没有调用付费出图或视觉模型。验证覆盖跨实例实时发布、幂等与并发、上传验证、展示/创作/分析用途区分、历史图片保留、旧确认卡与Worker拦截、原子回滚、迁移与Agent迟到屏障。浏览器覆盖上传到保存、已打开工作室自动同步、撤回展示、回包丢失后刷新重试及陈旧编辑保护。

本次安装新代码和数据库迁移需要一次本地服务升级；已备份旧数据库至`.data/themes-before-migration.db`。完成安装后，每次素材保存均不需要重启。本地目录初始版本及已有内测状态保持，管理员可以自行填写真实来源与用途后保存。

日志与最终测试结果见[开发进度](开发进度.md)本节对应记录。
