## 使用入口

- 工作室继续与Lumi沟通、确认需求和整理拍摄提案；“创作遇到问题？陪伴与帮助”绑定当前项目进入客服，可查询该项目次数/任务。
- 用户 `/support` 可不绑定项目询问公开规则；请求人工后可继续留言。无项目客服不能查询任意项目权益。模型与开发样例标记如实展示。
- 管理员 `/knowledge`：新建文档→导入文本或文件→等待索引→预览真实正文→审核并发布；下架立即阻止检索和新引用。未配置产品知识时指南/检索为空，不填假政策。
- 用户 `/guides` 阅读当前已发布指南，纯文本展示正文，不执行文档HTML。
- 员工/管理员 `/support`：领取用户请求的独立客服会话、文字回复、交还机器人。没有照片查看入口，不能通过客服取得创作材料。
- 工作室与客服的“查看本轮运行记录”显示实际步骤、角色和Release。知识引用按钮重新鉴权读取，不从模型输出拼任意来源链接。

受控开通客服员工：在后端运行 `uv run python -m app.cli create-admin --role staff --username <员工标识> --display-name <显示名称>`，密码交互输入，不能放命令参数。staff使用独立管理Cookie，仅有客服与能力目录访问权限；知识发布、模型、用户、权益、任务运营仍要求admin。原管理员凭证不变。

## 配置与向量空间

`resources/application.yaml` 的 `knowledge` 独立配置索引上限、分块大小、召回/结果数量、相似度、关键词降级及embedding插件。当前使用302实测成功的 `Qwen/Qwen3-Embedding-8B`，请求1536维并校验实际长度、有限值和归一化；数据库列为 `vector(1536)`。接口依据 [302 embedding文档](https://doc-en.302.ai/323761393e0)，SQLAlchemy接入依据 [pgvector-python](https://github.com/pgvector/pgvector-python)。

```yaml
knowledge:
  embedding_entrypoint: app.integrations.embeddings:CompatibleEmbedding
  embedding_options:
    model: Qwen/Qwen3-Embedding-8B
    base_url: https://api.302.ai/v1
    api_key_env: AI302_API_KEY
  keyword_fallback: true
```

这是知识向量模型，不替换后台当前LLM或gpt-image-2/low图片配置。密钥仍在原后端 `.env` 的 `AI302_API_KEY`；浏览器不接受密钥、端点或代码入口。其他embedding服务通过同一可信插件签名 `spec` / `embed(texts, timeout_seconds)`接入。

模型、归一化和插件参数共同构成空间指纹；换模型要重新索引并审核新版本，查询不把不同空间向量混排。改变维度需正式迁移。初次候选OpenAI embedding在302返回不可用/参数错误，未发布失败索引；经官方接口核对后选定实测返回1536维的Qwen。保留了失败记录，不以模型列表存在就认定可用。

生产禁止开发embedding。仅测试显式设置 `KNOWLEDGE_DEVELOPMENT_EMBEDDING=true` 使用带标识的哈希向量夹具；真实抽样始终关闭该开关。默认新索引失败时保留旧发布，不能把未完成版本发布。查询embedding故障时可用已评测的 `keyword-fallback-v1`，结果标明实际策略；没有证据就交由人工。

当前适合小知识库的精确检索；PostgreSQL在服务器分别召回，SQLite开发最多2000块，超过明确拒绝。向量近似索引与容量优化按M4实测增加。词法策略为中英文词和中文双字；查询与索引同策略，不把纯常见单字作为多字问题的主要关键词。

`agent.tools`可独立启停 `search_knowledge` / `get_catalog`；原工具继续注册。用户端导航顺序由各功能manifest.order配置，加入知识/客服不改变原发现/灵感库/项目顺序。角色路由词典、提示词/图/检索/评测版本在 `resources/agent/release.yaml`；预算仍由agent配置控制。模块关闭保留历史数据；知识指南可独立于创作/客服模块启用。六主题依然使用manifest/token，后台模型继续版本化发布。
