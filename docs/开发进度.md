## 实施决策

1. 本地默认 SQLite、私有目录和显式开发验证码，便于无外部账号联调；生产必须切换，数据库从不在 API 启动时自动建表。
2. 模型网关作为后端集成模块，通过协议、注册、路由、能力和不可变配置摘要提供扩展。不是另建一个微服务。
3. 主题 token 通过独立 manifest 注入，Hero/Intro 按需加载；同一视觉构图可以被新主题复用，也可以由插件完全替换。
4. 本阶段每个方案对应一张确认卡；修改保存新版本，旧卡不能执行。确认过期后重新保存；再做一组的专用 approval API 尚未增加。
5. 参考照直接绑定资产与人物，尚未实现区域蒙版。V1.3 新方案显式选择本次参考，区分底图/人物/风格，逐交付项冻结清单；文生图和底图编辑不要求人物槽。连续编辑保持祖先血缘校验与清理。
6. 会话消息已增加签名 cursor 分页，默认 20、上限 100，快照保留最近 60 条并提供旧页游标；其他业务列表仍为有上限数组。会话已接 SSE 与原生文字流，图片任务仍通过活跃任务轮询。
7. 供应商超时/结果未知或 Worker 崩溃时保留权益并转待核对。有接单凭据的异步任务可查询恢复；后台提供脱敏调用详情、审计核对和同语义取消。无凭据不重发、不强制结算。
8. 认证状态提供内存/Redis 实现，生产只允许 Redis 与数据库管理凭证。媒体运行协调使用共享数据库短行锁；未知远端尝试仍占槽。2026-10-22 用户决定：短信暂不接入，S3 延后迁移；本轮本地 M1 继续开发验证码和私有本地存储，不以这两项作为本地开发阻塞。管理二次验证与部署验收单独跟踪。
