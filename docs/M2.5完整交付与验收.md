# M2.5 完整开发与验收记录

2026-10-23。用户已授权按更新后的两份方案完整开发。本文件区分代码实现、隔离工程验证、真人效果与最终启用批准；不以代码完成代替真人质量验收。

## 工作室

- 人工体验验收后调整为左侧聊天、右侧素材/参数/方案/确认/结果。聊天理解四方式需求并整理右侧草稿，右侧全程不聊天也可完成创作。聊天流中不再复制完整表单和确认卡；同日修正记录见文末。
- 私有 `studio_drafts` 保存当前想法，带草稿版本和隐私代次。刷新恢复；多窗口冲突保留本地编辑并提示载入最新版本。敏感内容不写 URL 或 localStorage。
- 完整草稿自动准备服务端冻结 Plan/Approval，不预占权益、不调用生成模型。聊天与手动编辑共用确认单和稳定接受键；只有点击“按此方案生成”调用接受 API。接受成功后刷新能恢复原确认状态。
- 明确用户要求的模型输出标记 `intent=user_request`，仅在发送时草稿、需求与记忆版本仍匹配时应用到可撤销草稿；主动推荐保留“采用建议”。流式片段不应用，迟到输出不覆盖手动编辑。
- 删除照片、撤销授权或编辑草稿后旧确认被服务端拒绝。照片生成、补偿都没有聊天文本直通执行的入口。
- 旧常规路径的“写入→保存→打开确认弹窗→确认”，改为明确要求自动整理后的 **1 次最终确认**。主动建议另保留 1 次采用，必要授权、上传、领取试用仍明确操作，不虚报为全部一键。

## 主动视觉分析

`vision` 是网关独立能力，复用可插拔 LLM 传输契约；后台可分别设置模型、输出预算、图片张数、最长边和请求总字节数。默认未启用。

“帮我看看”显示本轮选图与用途，勾选同意后随消息受理；只发送所选项目图片或目录样片。工作室选图本身不会开启视觉。作品可选“直接修改”“和 Lumi 聊这张”“帮我看看这张”。

服务端排队时验证项目、素材、授权与上限；调用前再次检查原始摘要，临时读取/缩小/去元数据，按 Chat Completions `image_url` 发送。消息、Run、日志不保存 base64。最终提交仍受取消、隐私、模型版本和 Release 屏障保护。来源保留具体图片和摘要，旧分析不冒充新图观察；视觉观察不能直接写长期记忆；视觉修改建议强制保留“采用”步骤，模型自报 `user_request` 也不能绕过。

传输依据：[302 多模态官方文档](https://doc.302.ai/api-188445195)。该接口形态不证明任意模型都支持视觉；需对应候选实测。供应商通用[隐私政策](https://302.ai/legal/privacy/)不提供本项目所选各模型的统一固定照片留存期限，真实测试前仍须核对并披露。

## 模型候选、主题权利与 Release

后台保存改为候选，不改变当前运行路由；旧直接发布接口拒绝绕过。候选保留配置与摘要，审核需要逐能力实测记录、实际费用/账单依据及明确人工批准。启用才写不可变发布和指针；历史定义保留供已确认任务使用。视觉、对话、图片各自配置，候选导出到隔离环境测试，不以直接启用主环境来试模型。

正式样片新增来源、审核人、展示/衍生/模型处理用途及图片摘要。缺少匹配审核记录时不能作为正式镜头，仅去掉 `development_only` 不会放行。当前真实主题权利未代用户批准。

Agent 生产门禁补验完整路由题和全部 live 题的逐次重复样本，拒绝缺题、重复、失败、旧摘要、未审核或缺少质量/费用依据的报告。

## 非实时客服与质量反馈

- 留言待领取时机器人继续工作；员工领取时取消在途自动回复。用户可撤回留言或退出人工；旧员工窗口不能继续读取/回复，不重放旧消息。
- 质量反馈绑定一张成片，用户可额外授权一张人物参考。工作人员不取得完整补偿方案、原项目需求或其他输入；领取员工才可通过认证代理查看这两张图，不能访问全项目；每次请求重新验证权限、隐私代次、工单状态及30天期限。撤回/结单后停止新访问；不承诺收回已看到的内容。
- 同一原作品只创建一个质量反馈，人工审核后最多一个补偿 Plan。补偿沿用原作品对应交付项的冻结输入/模型，生成1张、0新增用户次数；新风格等新需求仍走普通新方案。
- 审核不生成，拥有者仍须点击补偿确认卡。重复确认防重；补偿成功、失败、取消不增加/扣除普通账户次数；原作品和审核记录保留。补偿作品不能再发放同类补偿。

## 删除与数据期限

取消选用和真正删除分开。删除参考或撤销人物时，可逐项选择已经确认、与图片无关的通用文字偏好，并明确声明其性质；不从旧聊天或视觉观察自动恢复。项目/账户删除清除全部偏好，不提供保留例外。新草稿和反馈正文纳入旧隐私代次清理，未聊过天的手动用户也会被清理。

本轮实验默认30天。工具仅管理 `.data/evals/m25/<UUID>/` 中的数据库、对象、报告、缓存、备份；到期墓碑拒绝旧备份复活，不能把文件夹恢复到旧 ID 后继续使用。主用户项目不进入这项实验过期规则。本地维护进程每分钟检查隔离目录；实验监督器到期停止服务后清理。主机离线时无法运行清理，下次本地服务维护或手动 cleanup 时执行。不得把可识别测试副本散放到管理目录外；外部备份系统未纳入时，不能声称外部副本清理已验收。

## 隔离实验操作

以下命令均从仓库根运行。prepare、导出、报告和费用操作不调用模型。

```sh
pnpm eval:m25 prepare
pnpm eval:m25 export-candidate --run <实验UUID> --candidate <候选UUID>
pnpm eval:m25 report --run <实验UUID>
pnpm eval:m25 begin-batch --run <实验UUID> --amount <本批估算人民币> --note <明确调用清单>
pnpm eval:m25 launch --run <实验UUID>
pnpm eval:m25 reconcile --run <实验UUID> --batch <批次UUID> --amount <实际人民币> --note <账单及折算依据>
pnpm eval:m25 cleanup
```

专用密钥变量为 `AI302_EVAL_API_KEY`，仅配置在服务端环境或受忽略的 `.env`，不放进聊天/报告。隔离启动使用自己的数据库/对象目录与 5473/5474/8300 端口，不沿用主项目或主发布指针。启动前需逐项填写私有 manifest 的成年人同意、两主题来源、专用Key、供应商说明和工程就绪证据，不能仅为运行而虚填 true。

每批结束先等图片、对话和知识索引任务终结，未知提交先核对原请求，再停止隔离服务核账；工具持有运行锁，运行中禁止结清/打开批次。

预算为100元人民币等值的**规划预算**。上一批费用未知时不允许打开下一批；对话、看图、图片、embedding、失败/诊断/重做及新增样片制作都应计入批次。上游迟到扣费不能被本地估算变成硬封顶。本次开发没有执行真人或付费模型回归。

B01–B12 清单由工具生成，保持三人×两主题×两张；辨识度由测试者评，风格/可交付性由用户评。当前没有代填评分、账单、主题权利或质量批准。

## 人工体验验收修正（2026-10-23）

用户实际体验后明确调整：**左侧以聊天为主，右侧负责素材、参数、提案和生成确认**。此条取代早期“两侧各放一套完整表单”的界面方案；聊天仍可理解四种创作需求并整理右侧草稿，右侧仍可全程不聊天完成创作。

- 移除聊天流中的完整创作表单、结果列表、确认卡及重复引导按钮；记忆与运行信息折叠。视觉选图只有用户主动展开时显示。
- 普通明确要求可整理当前方式的可撤销草稿；LLM 建议切换创作方式时，先展示右侧候选和差异，用户采用后才切换，不因收到回复自动跳到拍同款。候选采用继续检查草稿、需求、记忆和隐私版本。
- 私有草稿完成载入前显示准备状态，避免先渲染默认方式再跳到已存方式。
- 右侧独立滚动，底部固定显示生成按钮、张数、次数及阻塞原因。即使缺素材、次数不足或冻结方案失败，按钮仍可见但禁用；不把真实模型拒绝内测样片变成“按钮消失”。
- 对设计写真选用了内测风格参考的情况，提供明确的取消参考操作；不会自动替换用户输入，不会绕过样片审核。拍同款仍要求已审核样片。
- 当前用户项目仅查看、刷新并切换创作画面/结果页，没有提交聊天、调用真实模型、领取权益或生成照片。保留原草稿和作品。

## 最新交互约定：纯聊天与自动配置（2026-10-23）

用户截图明确移除左侧模型信息、连接提示、记忆入口、运行详情和看图选择。左侧现仅承载聊天消息、输入及必要的发送/停止/错误反馈；消息署名不再带模型ID。记忆、只读来源、运行记录及主动看图的选图/用途/同意集中到右侧默认折叠的辅助区，既有权限与显式记忆确认保持有效。

本节取代上一轮“跨模式修改先点采用”的规则。用户明确提出的可执行要求，经后端结构校验并确认发送时草稿/需求/记忆版本仍有效后，直接更新右侧当前配置，允许合理调整方式、主题/镜头、画幅、张数、氛围、修改/保留项。原生流式片段、失败输出和迟到输出不能修改配置；不会覆盖用户等待期间的新编辑。模型额外主动推荐的创意仍征询，不把未经请求的推荐强行写入。

Agent提示区分本次修改和长期记忆：本次改光线、背景、画幅或数量使用当前草稿补丁；只有明确要求长期记住或更新已确认需求卡时才提出记忆建议。创作方式按已选底图、人物参考及用户意图判断，歧义在聊天中追问，不能仅凭“替换人物”盲切拍同款。上下文补充各方式的开发状态、样片内测/用途审核标志，避免推荐未放行的组合。上传和人物授权仍由用户完成，最终图片生成仍须点击确认，不因自动更新配置而自动付费执行。
