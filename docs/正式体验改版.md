# 梦幻摄影师正式体验 · V1.3

用户确认原型方向后，正式 `/` 和 `/projects/:projectId/studio` 已采用柔和光晕、圆润半透明表面和“摄影师引导 + 影像画布”。`/preview` 与 `/preview/studio` 保留独立演示用于对照。原型计时器、示例人物和样片相册没有迁入正式创作逻辑；V1.2 为首轮视觉迁移；V1.3 增加四种正式创作方式、套系与逐项图片协议，数据库表结构保持兼容，详见[四种创作方式接入](四种创作方式接入.md)。

## 正式用户流程

1. 访客浏览首页，输入想法或选风格样片。未登录时先登录，随后命名项目并确认单/双人类型；初始想法在项目创建成功后绑定该项目并带入草稿。
2. 工作室左侧已由 V1.6 升级为后端 LLM 摄影师对话，右侧为准备画面、提案和生成结果。人物授权及参考照上传位于画布侧面板；手机通过对话/画布页签切换。
3. 引导收集用户原话，点击“写入草稿”才追加到补充要求；“暖一点 / 清透一点”只修改氛围草稿。这些操作不写服务器、不预占权益、不创建 Job。
4. 保存形成后端冻结提案及确认卡；仍需明确确认，才预占权益并创建任务。旧卡不能因 UI 改版绕过版本、授权、冻结供应商或幂等约束。
5. 结果区显示实际任务阶段和已授权私有作品，可取消未完成任务、查看及下载作品。开发图片插件的测试卡明确标示；样片只存在灵感区。选片为当前页临时选择，未提供持久化收藏。

首页想法、未保存便签和表单仅在应用内存；不写 URL、浏览器历史状态或 localStorage。主题偏好仍只保存非敏感 themeId。真正保存提案后，补充要求按现有方案接口持久化。离开或刷新页面可能丢失未保存的内容。

## 草稿与确认保护

- 实例边界为 projectId，切主题不会重建表单、摄影师便签、当前结果选择或待确认动作键；生成 style_id 与外观 theme_id 独立。
- 初次加载时可恢复最近保存的提案，后台刷新不覆盖已编辑内容。
- 当前草稿改动、项目人物资料修订或其他页面保存新版本后，旧卡关闭确认；重新保存新提案后再确认。
- 其他页面保存的新版本可显式载入；若会替换未保存草稿，先提示用户。保存错误和确认错误保留可见反馈，幂等键在同一动作重试时复用。
- 取消状态、结果未知和权益结算使用服务端状态，不制造完成百分比或提前宣称返还。

## 主题与网关配置

| 配置位置 | 职责与生效方式 |
| --- | --- |
| `apps/web/src/config/experience.ts` | 默认主题、摄影师名称/说明、输入显示限制；前端构建生效 |
| `apps/web/src/themes/*/manifest.ts` | 自动注册的主题；`enabled: false` 可隐藏外观；token、版本、Hero/Intro 及可选 atelier 展示参数 |
| `ThemeManifest.atelier` | 标题、说明、封面/画布各自的焦点、辅助图、色谱；可复用 DreamHero，也可替换整个 Hero |
| `features/atelier/atelier.css` + `production.css` | 共享布局及正式 token 映射，不按供应商或 themeId 编写业务分支 |
| `services/backend/resources/catalog.yaml` | 可生成风格、版本、项目类型、画幅与张数约束；主题外观启停不修改这些业务定义 |
| `services/backend/resources/application.yaml` | modules、features、providers、routes、适配器版本/能力及非秘密部署参数；后端校验/重启生效 |
| 后端环境变量 | 模型凭证与其他密钥；不进入前端配置、VITE_* 或公共资源 |

网关继续遵循 integrations 协议、注册与冻结配置哈希。默认路由改变后，待确认方案须重存，已确认任务仍使用冻结配置；旧适配器及版本须保留。本轮没有绕过网关新增前端模型请求。

新增主题、适配器与模块的步骤见[插件接入](插件接入.md)。当前关闭某个主题只影响外观选择，不自动删除服务端生成风格。

## Agent 实现边界

V1.6 已接入真实 LLM、项目 Conversation/Run、LangGraph 短图、固定只读上下文、追问和结构化建议。`chat_enabled` 与模块装配控制聊天；后台模型发布决定新轮次的 LLM。当前采用快照轮询，不提供 token 流或通用工具循环；正式写入和生成继续由用户确认。具体边界和验收见 [M2 创作 Agent](M2创作Agent.md)。
