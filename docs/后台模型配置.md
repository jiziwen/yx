# 后台 302.AI 模型配置

入口：[本地后台 /models](http://127.0.0.1:5274/models)，需要独立管理员会话。当前生效模型与版本以页面读取的服务端状态为准；历史初次发布和联调记录见下文。M2.5 不替用户切换现有模型。短信继续使用开发验证码，照片继续使用私有本地存储。

## 如何换模型

在“302.AI 模型”页点击“读取 302 模型列表”，获取当前账号可见的模型 ID。模型输入框支持搜索和手填，便于新模型上线后直接配置，不需要修改前端源码。

- 图片：分别设置文生图、人物参考、图片编辑模型，以及开放操作、总输入/人物参考/风格参考图片数、人数和画幅。
- 质量：GPT Image 接口显式发送 low/medium/high/auto；当前开发默认 low。其他模型选择“302 统一图片接口”，其质量参数须按对应供应商协议确认，不能认为同名档位通用。
- 语言：选择大语言模型 ID 和单次最大输出 token。Sonnet 5.5 的标识为 claude-sonnet-5-5。正式工作室 Agent 使用此处发布的语言模型进行需求理解、追问与提案整理；当前轮次冻结版本，新消息使用新版本。生成图片仍需独立确认。
- 视觉：单独配置模型、输出预算、输入张数、最长边和总图片字节上限；默认关闭，不能因为聊天模型名称相同就视为已验证视觉。
- 保存：点击“保存为待验收候选”，只记录候选配置，不改变当前运行模型、不调用模型。候选摘要绑定模型配置、执行代码与套系目录；代码或目录变化后须重建候选并重测受影响范围。
- 继续编辑：保存成功后显示候选确认和审核入口；刷新或重新打开页面会回填最新的待实测候选。页面顶部单独展示当前生效版本，可点击“使用当前生效配置”切回查看，也可在候选列表中“载入配置”。审核启用成功后，当前版本和编辑表单同步更新。
- 验收：使用候选导出工具在隔离环境验证。后台按候选能力列出必须提供的文字/参考/编辑、模板、单人/双人、输入边界、LLM 和视觉证据；只开放单人能力时不会要求双人证据，也不能用单人结果批准双人。
- 启用：填写全部能力证据、实际费用与账单依据、审核理由，并明确批准后才切换生效版本。证据内容由审核人负责，系统检查完整性和摘要，不会自动判断真人质量。旧 PUT 直接发布接口返回 `MODEL_CANDIDATE_REQUIRED`，不能绕过候选流程。API 和 Worker 继续从同一数据库指针刷新，无需重启。

密钥只放在 services/backend/.env 的 AI302_API_KEY。页面仅展示“已配置/未配置”，没有读取、编辑或回显密钥的接口；不能从浏览器修改上游 URL、Python 插件入口或服务端密钥变量名。

## 版本与任务保护

每次设置发布保存不可变 model_releases 和当前 model_setting_heads 指针，与审计同事务提交。表单携带 expected_revision；两人编辑同一版本时仅一人成功，另一人刷新后重新保存。相同内容不会增加版本。

图片插件 ID 由实际图片配置摘要生成。改语言模型预算不会改变图片插件 ID。修改图片模型/质量/能力后，未确认旧提案须重新保存确认；已经确认的任务仍可使用历史插件定义、原请求键与原接单凭据继续执行和核对，不会切到新模型。API 与独立 Worker 都从数据库发现新版本。

历史模型配置不能通过修改 YAML 或手工删除发布表清除；回退涉及在途任务时须先备份、停止派发并处理未决任务。迁移 a06b4bffb961 仅添加两个配置表，不改写原项目、资产、任务和权益。候选不发布；经过明确人工审核启用的插件标记 release_status=validated。该标记不代替 Agent 的生产 Release 门禁、真实人物质量批准或公开上线验收。

## 原生 GPT 图片协议

AI302GPTImage 使用 POST /v1/images/generations 或有序 multipart /v1/images/edits，显式传 n=1、quality 和匹配画幅的 size，并启用 async=true。接单 ID 先保存，再通过 GET /async_result 查询原任务；使用现有 Job、预占和私有交付事务，不透明重发。

当前固定画幅尺寸：3:4 为 768×1024，4:3 为 1024×768，1:1 为 1024×1024。GPT Image 2 不发送 input_fidelity。结果下载沿用官方文件主机、公共 HTTPS、禁止重定向和字节上限保护；上游 JSON/dict 结果和数值 usage 白名单均支持。

协议依据：[302 图片生成](https://doc.302.ai/288853804e0)、[302 图片编辑](https://doc.302.ai/288853817e0)、[302 异步结果](https://doc.302.ai/322999617e0)、[OpenAI 官方图片参数](https://developers.openai.com/api/docs/guides/image-prompting)。

## M2.5 隔离候选与回退

按 [完整交付记录](M2.5完整交付与验收.md) 使用 `pnpm eval:m25` 导出候选，专用 `AI302_EVAL_API_KEY` 与主 Key 分开。实验数据库、对象和账单批次独立，生成仍逐单点击确认。实验运行中或有未决任务不能结清批次；上一批实际费用未知不能开始下一批。

回退通过选择历史配置并重新走当前代码/目录对应的候选审核。不能直接删除发布指针或历史定义；已经确认的任务仍沿用冻结插件核对原请求。历史候选摘要若与现代码不同，重新保存同配置为新候选，不冒用旧代码下的批准。
